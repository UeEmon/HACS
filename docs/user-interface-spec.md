# HACS ユーザインターフェース仕様 v1

状態: 二方式対応の画面設計。方式選択、受信設定コード、更新期間表示、プリセット管理、共通鍵の即時更新を実装済み。直接コード指定UI、ナビゲーション、詳細領域、カード表示など全体の画面再構成は未完了。

## 基本構成

Webブラウザで操作する日本語UIとする。Windows・Mac・Linuxで共通の画面を使用する。送信部と受信シミュレータは独立したコンテナ・画面とし、互いの画面へ移動するリンクを設ける。リンク先は設定可能にし、現在のホスト名を使用する。初期ポートは送信8787、受信8788。音声は画面を開いた端末から出力する。

画面上部にHACS、画面名、処理状態、送信／受信シミュレータへのナビゲーションを配置する。基本操作では呼び出し相手先と方式を選ぶだけでよい。変換規則の識別子や周波数表は「詳細」にまとめる。無線機インターフェースは保留中のため、主操作は「音声生成」「再生」「WAV保存」とし、再生完了を無線送信完了や相手の応答と表示しない。

## 送信画面

上から「呼び出し先」「生成結果」「操作」「詳細設定」の順に配置する。PCでは呼び出し先と生成結果を横に並べ、狭い画面では縦に並べる。

| 領域 | 表示・操作 | 初期値・動作 |
|---|---|---|
| 呼び出し先 | 呼び出し相手先 | 半角数字4桁。例5501。先頭ゼロを保持 |
| 呼び出し先 | 呼び出し方式 | 「従来16音」「SELCAL 32」。初期値は従来16音 |
| 呼び出し先 | コード指定方法 | 「呼び出し相手先から変換」を既定。「コードを直接指定」は詳細設定内 |
| 生成結果 | 呼び出し相手先、方式、呼び出しコード | コードを大きく表示。例 `5501 → EM-DL` |
| 生成結果 | 割当元 | 「HACS独自変換」または「直接指定」。実機登録済みと推定しない |
| 操作 | 音声を生成 | 入力が有効で処理中でなければ有効 |
| 操作 | 再生／停止 | 生成後に再生可能。再生中は停止を常に操作可能 |
| 操作 | WAVを保存 | 生成後のみ有効。呼び出し相手先・方式をファイル名に含める |
| 詳細設定 | WAV出力レベル | 1〜90%、初期50%。PCM振幅であることを併記 |
| 詳細 | 変換バージョン、PCM形式、信号時間 | 読み取り専用 |

呼び出し相手先・方式・直接コード・レベルの変更で生成済み音声を無効化し、再生と保存を無効にする。生成中・再生中は呼び出し条件の編集を無効にする。再生のための確認ダイアログは設けず、利用者の再生ボタン操作で開始する。自動再生は行わない。

入力欄の近くに具体的なエラーを表示する。「呼び出し相手先は半角数字4桁で入力してください」「このコードにはSELCAL 32の音が含まれています。方式を確認してください」などとし、自動で方式やコードを変えない。

| 状態 | 表示例 | 操作 |
|---|---|---|
| 入力待ち | 呼び出し先を入力してください | 生成は無効 |
| 生成可能 | 音声を生成できます | 生成が有効 |
| 生成中 | 音声を生成しています | 二重生成を防止 |
| 生成完了 | 音声を生成しました | 再生・保存が有効 |
| 再生中 | 音声再生中 | 停止が有効 |
| 再生終了／停止 | 再生を終了しました／停止しました | 再生・保存が有効 |
| エラー | エラー理由と修正方法 | 条件を修正して再生成 |

生成完了と再生終了の表示には「無線機への送信状態・相手の応答は未確認」を併記する。将来の登録コード対応表は別の指定方法として追加し、未登録なら生成できない。独自変換へ自動的に戻さない。

## 受信シミュレータ画面

上から「自機設定」「受信音声」「判定結果」「検出詳細」の順に配置する。

| 領域 | 表示・操作 | 初期値・動作 |
|---|---|---|
| 自機設定 | 自機番号 | 半角数字4桁。初期5501 |
| 自機設定 | 受信できる音 | 「従来16音」「32音（従来16音を含む）」 |
| 自機設定 | 自機の呼び出し方式 | 「従来16音」「SELCAL 32」。受信能力を超える選択は無効 |
| 自機設定 | 自機の呼び出しコード | 入力から変換し表示。直接指定は詳細設定内 |
| 受信音声 | WAVファイル選択 | ファイル名、容量を表示 |
| 受信音声 | 受信判定 | 自機設定・ファイルが有効なら有効 |
| 判定結果 | 自局一致／他局／未検出 | 大きな文字と状態アイコンで表示 |
| 判定結果 | 通知音 | 自局一致時に鳴らす。初期ON |
| 検出詳細 | コード、HACS呼び出し相手先候補、判定、検出時刻 | 複数の呼び出しは検出順に行表示 |
| 詳細 | 追加音の有無、音長、間隔、変換バージョン | 必要時に展開 |

受信能力と自機方式は別の設定である。32音受信能力で従来16音の自機コードを照合できる。受信能力を16音に変更する際、自機方式が32音なら不整合を表示し、利用者が修正するまで判定を無効にする。自機設定またはファイルの変更で前の結果を消し、新たな判定を求める。

判定中は設定編集と追加判定を無効にする。正常終了時に入力を再び有効にする。通知音が再生できなくても画面の自局一致表示は維持する。通知音の停止操作を用意する。ファイル解析と実無線受信を区別するため、画面名と説明に「受信シミュレータ」「WAV解析」を表示する。

| 判定 | 表示 | 色の補助 |
|---|---|---|
| 自局一致 | 自局への呼び出しを検出しました | 緑 |
| 他局 | 他局への呼び出しを検出しました | 青 |
| 未検出 | 有効な呼び出しを検出できませんでした | 灰 |
| 入力・解析エラー | エラー理由と修正方法 | 赤 |

HACSの逆変換結果は「HACS呼び出し相手先候補」と表示する。未割当コードなら「HACS割当範囲外」。独自規則から得た番号を実際の航空機の識別確認として扱わない。未検出だけから相手が16音／32音に対応していないと断定しない。

## 表示・入力・保存

- ダークブルーを基調とし、コードは等幅書体で大きく表示する。主要ボタンは44×44 CSS px以上の操作領域を確保する。
- キーボードで全操作を行えるようにし、ラベル、フォーカス表示、状態読み上げを設ける。色だけで結果を区別しない。
- 呼び出し相手先は数値入力型にせず文字列として扱い、数字キーボードを指定する。4桁未満の入力を自動でゼロ埋めしない。
- 幅320 CSS pxでもページ全体の横スクロールを避ける。検出一覧は狭い画面ではカード表示に切り替える。
- 方式、出力レベル、自機設定、通知音設定は各画面のブラウザに保存する。呼び出し相手先、音声ファイル、解析結果は自動保存しない。
- 接続失敗は操作領域に表示し、再試行は利用者の操作で行う。未実装の32音操作は有効なボタンとして公開しない。

## 操作例

送信: 方式選択 → 呼び出し相手先入力 → 表示コード確認 → 音声生成 → 再生またはWAV保存。

受信試験: 受信能力・自機方式・自機番号を設定 → 送信画面で保存したWAVを選択 → 受信判定 → 自局一致／他局／未検出を確認。

方式選択は[二方式対応仕様](dual-mode-spec.md)の `selcal16` / `selcal32` に対応する。自機方式は受信APIの `own_mode` に対応する。技術識別子は通常操作に必要な情報ではないため詳細表示に置く。

## 画面の受入条件

既定の従来16音操作を維持する。方式変更によるコード更新・音声無効化、0000の保持、入力エラー、二重操作防止、停止操作、通知音が鳴らない場合の結果表示を確認する。32音受信能力で両方式を試験する。PCとiPad相当の画面幅、キーボード操作で確認する。画面遷移リンクは別ホスト・設定ポートでも正しい接続先を使う。

## 自動更新・登録管理の追加画面

送信画面はプリセットの選択、名称・呼び出し相手先・方式の登録／更新／削除を提供する。受信設定コードはその時点の鍵と期間で再計算する。両画面で更新周期・期間・次回JST更新時刻・鍵識別子を表示する。送信画面の共通鍵管理は管理トークンによる新しい親鍵への即時切替と履歴表示を提供する。トークンは操作後に消去し、永続保存しない。受信画面では過去WAVの試験期間を明示指定できる。操作と検証範囲は[説明書](automatic-rotation-and-management.md)を参照。
