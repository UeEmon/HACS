# LRTシリーズの公開資料確認

国際電気・日立国際電気のLRT送信機について公開資料を調査しました。**LRT-20( )とLRT-35Cは、海上自衛隊の公開資料で「HF送信機」と明記されています。** 製造会社表記はいずれも日立国際電気です。[1][2]

確認できたのは型式・品名・製造会社等です。音声入力・PTT・遠隔制御の接続仕様書本体は、今回の調査では見つけられていません。

## 型式ごとの確認結果

| 型式 | 資料上の記載 | 確認した範囲 | 出典 |
|---|---|---|---|
| LRT-20( ) | HF送信機、日立国際電気 | HF機という分類とメーカー表記 | [1] PDF 6ページ、番号14 |
| LRT-20、LRT-20-2、LRT-20B( )、LRT-20C-2、LRT-20D、LRT-20D-( ) | 送信機、日立国際電気 | 個別型式の掲載。枝番間の接続互換性は未確認 | [2] PDF 6ページ、番号111～116 |
| LRT-35C | HF送信機、日立国際電気 | HF機という分類、特定型式とメーカー表記 | [2] PDF 6ページ、番号118 |
| LRT-35B | 送信機、日立国際電気 | 型式とメーカー表記。35Cから帯域・接続仕様を推定しない | [2] PDF 6ページ、番号117 |
| LRT-7( )、LRT-8( )、LRT-9C( )、LRT-33( ) | 送信機用部品、日立国際電気／国際電気 | 部品調達公示への掲載。HFの明示・端子仕様は今回未確認 | [3] PDF 14ページ、番号163～165 |

PDFページは1始まりです。括弧付き型式は枝番を含む表記として記録し、枝番のない機種と同じ仕様にはしていません。

LRTという型式接頭辞だけでは、メーカーも周波数帯も確定しません。同じ公開資料[2]には、日本無線のLRT-10C（番号99）、日立国際電気の飛行情報放送装置用送信機LRT-17B（番号110）もあります。LRT全体を1つのHF機・メーカー・接続方式として扱わず、具体的な型式で判断します。

## 仕様書番号の手掛かり

防衛装備庁の「廃止された防衛省仕様書一覧」には、`DSP C 5108(1)`、送信機LRT-33の項目があります。[4] 一覧の記載から仕様書本体の内容は読み取れず、現行仕様やLRT-20・LRT-35の接続仕様へ転用しません。

## HACSでの扱い

接続仕様の調査対象として、特定型式とHF分類を確認できた **LRT-35C** のドライランサンプルを追加します。

設定ファイル: [hitachi-lrt35c-dry-run.json](../../radio_templates/hitachi-lrt35c-dry-run.json)。`backend`は`dry_run`です。公開資料にない端子・レベル・極性・通信方式は`null`のままです。前待ち0.3秒・後待ち0.2秒・PTT上限5秒はHACSの模擬値であり、LRT-35Cの装置仕様値ではありません。

```bash
python3 radio_dry_run.py --profile radio_templates/hitachi-lrt35c-dry-run.json --tail 5501 --mode selcal16
python3 radio_dry_run.py --profile radio_templates/hitachi-lrt35c-dry-run.json --tail 5501 --mode selcal32
```

HACSの現在の鍵・周期設定に従い、WAV生成・PCM内部確認・音声/PTTの模擬順序を確認します。JSONに`dry_run: true`、`physical_output: false`を出力します。LRT-35Cのハードウェア動作を再現するものではなく、実出力用`radio_host.py`では拒否されます。

| 項目 | 今回の状態 |
|---|---|
| 周波数範囲、電波型式、音声帯域、出力 | HFという分類以外は未確認 |
| 音声入力コネクタ・ピン・レベル・インピーダンス | 未確認 |
| PTT入力・送信許可・解除の電気条件 | 未確認 |
| 前後待ち・送信開始状態の取得 | 未確認 |
| 外部管制装置・変調装置を介した接続要否 | 未確認 |
| Ethernet・シリアル・1553の対応有無 | 未確認 |
| 機種別コマンドと応答、枝番間の差 | 未確認 |

実機の型式・枝番・構成と装置仕様書、接続図、遠隔制御仕様を確認した後に機種別アダプタへ展開します。接点PTT、RS-232コマンド、Ethernet、1553のいずれも、現段階で対応していると推定しません。
