# 国際電気・日立国際電気製HF無線機の公開資料確認

国際電気および日立国際電気の名称でメーカー・海上自衛隊・防衛装備庁の公開資料を調査しました。**HRC-121とHRC-122について、HF無線機という品名と日立国際電気という製造会社表記を海上自衛隊の公開資料で確認しました。**

一方、今回の調査では音声入力・PTT端子・遠隔制御の詳細を定める仕様書本体を見つけられていません。調達資料で機種名を確認したことと、HACSを接続するための仕様を確認したことは区別します。

## メーカー名称

メーカー公式の商号変更案内では、株式会社日立国際電気から株式会社国際電気への商号変更日を2024年12月27日としています。[1] 本文では古い資料の製造会社表記をそのまま記録し、現行の機器仕様や接続条件を商号変更から推定しません。

## HF機種を明示した資料

海上自衛隊の公開公示 `K-1-1624-0021.pdf` の別表第1、PDF 11ページ（1始まり）に次の記載を確認しました。[2]

| 型式 | 資料上の親機器名 | 公開資料で確認した構成品 | 製造会社欄 | 一連番号 |
|---|---|---|---|---|
| HRC-121( ) | HF無線機 | 制御器 `N-C-1258/HRC-121`、送受信機 `N-RT-182B/HRC-121` | 日立国際電気 | 352・353 |
| HRC-122 | HF無線機 | 送受信機 `N-RT-210/HRC-122`、RF増幅器 `N-AM-413/HRC-122`、整合器 `N-CU-251/HRC-122`等 | 日立国際電気 | 354～359 |

括弧や枝番を省略して別型式と同一仕様にはしません。ここで確認したHRC-122を、HRC-122B等の型式の接続仕様に自動的に適用することもありません。構成品名から音声やPTTの配線順序は読み取っていません。

## 艦船用器材の調査候補

公開公示 `K-07-0100-0030.pdf` のPDF 14ページには、次の品目と製造会社表記があります。[3]

| 品目名 | 掲載番号 | 今回確認した範囲 |
|---|---|---|
| 無線装置NORC-50( )用部品 | 151 | 型式と日立国際電気／国際電気の表記 |
| 送信機LRT-20( )用部品 | 154 | 同上 |
| 送信機LRT-35( )用部品 | 155 | 同上 |
| 送信機ORT-24( )用部品 | 156 | 同上 |
| 送信機ORT-49( )用部品 | 157 | 同上 |

この公示は部品調達（製造）の資料です。これらの品目をすべてHF機と断定したり、Ethernet・シリアル・1553対応を推定したりする根拠にはしていません。

また防衛装備庁の「廃止された防衛省仕様書一覧」で、`DSP C 5142`が送信機ORT-49・ORT-49-1の仕様書名称として掲載されていることを確認しました。[4] これは廃止仕様書の一覧であり、仕様書本体の取得、現行仕様への適合、特定機のPTT条件の確認を意味しません。

## HRC-122の検討用サンプル

[hitachi-hrc122-dry-run.json](../../radio_templates/hitachi-hrc122-dry-run.json)を用意しました。

- 公開資料で確認した型式・製造会社・構成品と出典を記録します。
- バックエンドは`dry_run`に限定します。実機端子、音声入力レベル、PTT方式・極性は未設定です。
- アナログ音声/PTT、Ethernet、シリアル、MIL-STD-1553の対応有無はすべて`null`です。これらは確認待ちの調査欄であり、本機が備える接続方式の一覧ではありません。
- 前待ち0.3秒・後待ち0.2秒・PTT上限5秒はHACSの模擬設定です。メーカー仕様値ではありません。

```bash
python3 radio_dry_run.py --profile radio_templates/hitachi-hrc122-dry-run.json --tail 5501 --mode selcal16
python3 radio_dry_run.py --profile radio_templates/hitachi-hrc122-dry-run.json --tail 5501 --mode selcal32
```

現在のHACSの鍵・周期設定でコードを計算し、音声生成・PCM内部確認・音声とPTTの模擬順序を実行します。実際のHRC-122の反応を模擬するものではありません。`dry_run: true`と`physical_output: false`を出力します。この設定を実出力用`radio_host.py`へ渡すと拒否します。

| 遠隔制御プロトコル・コマンド・応答 | 未確認 |
| Ethernet・シリアル・1553の対応有無 | 未確認 |
