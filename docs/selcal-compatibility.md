# SELCAL互換性確認結果

確認日: 2026-10-11 / 対象: HACS-TN16-v1・従来16音のPCMエンコーダ。

## 判定

従来16音SELCALのコード形式と名目上のデジタル音声構成は公開資料と一致する。実機相互接続・割当コードの一致・航空通信装置としての適合性は未確認。SELCAL 32の追加16音は未対応。

## 照合表

| 項目 | 公開資料の条件 | HACSの結果 | 確認範囲 |
|---|---|---|---|
| 使用文字 | 従来16音の文字集合 | A〜H、J、K、L、M、P、Q、R、S | 実装と全10000変換結果 |
| コードの構成 | 2文字の組を2組、文字重複なし、各組内は昇順 | 全10000コードが条件を満たす | 公開規則を独立した検証条件として確認 |
| 周波数 | ASRIの従来16音の表 | 全16音の定数が一致 | 名目周波数、物理出力は未測定 |
| 音の順序 | 第1組2音同時、その後第2組2音同時 | PCM波形と参照正弦波が量子化誤差以内で一致 | 全16音、出力レベル1%、50%、90% |
| 音長 | 1.0 ± 0.25秒 | 各組48000サンプル / 48000 Hz = 1.0秒 | WAV上の時間 |
| 組の間隔 | 0.2 ± 0.1秒 | 9600無音サンプル / 48000 Hz = 0.2秒 | WAV上の時間 |
| 周波数安定度 | ±0.15% | 定数と生成式は名目値 | DACクロック、RF経路は未確認 |
| 2音のレベル | RF信号中で差3 dB以内 | デジタル生成式の2成分は同じ振幅 | 音声・RF経路の利得差は未測定 |
| 音声歪み | 送信RF信号中で15%以下 | PCM参照波形との差は丸め誤差のみ | RF信号での歪み測定は未実施 |
| 相手のコード | 機上デコーダに設定されたコードで呼び出し | HACS独自変換によるコードを生成 | 実機の設定との一致は未確認 |

PCMの丸め誤差は16 bit振幅値で最大0.5 LSB以内だった。これはデジタル波形の検証であり、RF信号での周波数安定度・音声歪み・音量差の規定を測定した結果ではない。

## 既存のコード割当との関係

`5501 → EM-DL` はHACS独自の変換例。実際の機番号5501にEM-DLが設定されているという意味ではない。既存機を呼び出すには、その機に設定された実コードを用いる必要がある。現在の試験用直接コード指定API/CLIでは実コードの音声を生成できるが、機番号と実コードの登録・照合機能は未実装。

HACS受信シミュレータは同じ独自変換規則を使うため、送受信の一致は確認できる。この結果は市販・機上の独立したSELCALデコーダとの相互接続確認には代わらない。

## 方式の範囲

ASRIの2024年版ガイドには12音・16音・32音の区分がある。12音では2970コード、従来16音では10920コードとなる。したがって12音のみの装置に対し、4桁10000通りの一意変換をすべて対応させることはできない。

32音対応機器でも従来16音コードの処理可否は機器仕様と設定で確認する。HACSは追加16音を生成・検出しないため、32音全体の対応装置とはいえない。SLCAA資料の地上局エンコーダに対する全音対応の要求も、本実装では満たしていない。

## 実施した検証

- 既存15項目を再実行し合格: 全10000通りの一意性・逆変換、送受信処理、API等。
- 追加3項目が合格: 公開資料の16音表照合、アプリのコード検証関数に依存しない全10000形式確認、参照周波数によるPCM波形・時間照合。
- Docker実行、DACによる実音声出力、RF送信、実機デコーダの通知は未確認。無線機インターフェースは保留。
