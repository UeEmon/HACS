HACS

HF Aircraft Calling System

航空機の4桁の機番号から呼び出し音声を作成します。

HACS-TN16-v1で内部コードに変換します。実機の割当済みSELCALコードとは一致確認が必要です。

2音同時 × 1.0秒 → 無音0.2秒 → 2音同時 × 1.0秒。48 kHz / 16 bit / mono。

機番号を入力してください。

WAVを保存

再生音は、このブラウザを開いた端末から出ます。無線送信・PTT制御は未接続です。SELCAL 32は未対応。

受信シミュレータ: http://localhost:8788
保存したWAVを受信画面で読み込むと、自局コードとの一致を確認できます。
