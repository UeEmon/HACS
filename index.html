航空機用・16音／32音

HACS

HF Aircraft Calling System

航空機の4桁の機番号から呼び出し音声を作成します。

選択した方式のHACS規則でコードに変換します。実機の割当済みSELCALコードとは一致確認が必要です。

受信側に設定するコード—

HACS独自変換。実機の登録コードとの一致は別途確認が必要です。

2音同時 × 1.0秒 → 無音0.2秒 → 2音同時 × 1.0秒。48 kHz / 16 bit / mono。

機番号を入力してください。

WAVを保存

再生音は、このブラウザを開いた端末から出ます。無線送信・PTT制御は未接続です。16音／32音に対応。

受信シミュレータ: http://localhost:8788
